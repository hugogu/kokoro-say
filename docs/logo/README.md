# ksay logo

| File | Use |
| --- | --- |
| `ksay-logo-light.svg`, `.png` | Mark and wordmark, for light backgrounds |
| `ksay-logo-dark.svg`, `.png` | The same, for dark backgrounds |
| `ksay-mark.svg`, `ksay-mark-512.png` | The mark alone: avatars and icons |
| `social-preview.png` | 1280 × 640, for the repository's social preview image |

The mark is a terminal prompt followed by a waveform: type a command, hear a voice.
The green of the prompt returns in the **k** of the wordmark, which is how the name is
said ("kay-say").

| | |
| --- | --- |
| Prompt and **k** | `#3fb950` |
| Waveform | `#79c0ff` to `#388bfd` |
| Tile | `#263247` to `#0b0f14` |
| Wordmark | `#f0f6fc` on dark, `#1f2328` on light |

The wordmark is JetBrains Mono ExtraBold, © The JetBrains Mono Project Authors, under the
SIL Open Font License 1.1, converted to outlines so that the logo needs no font. The mark
is original. Everything here is rebuilt by `uv run scripts/make_logo.py`; change the script
and regenerate rather than editing the files. The logo is MIT-licensed with the rest of the
project.
